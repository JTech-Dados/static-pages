Tokens de API

Para scripts e automações publicarem páginas no seu time, sem abrir o painel. O token vale como a sua conta: quem o tiver publica o que você publicaria. Trate como senha.

Como usar

Troque o token por uma sessão e publique com a API do painel. O envio precisa informar o tamanho (Content-Length); o curl --data-binary já faz isso.


      

      
Pedir ao Claude

      
Para quem usa o Claude Code ou o Claude Desktop com acesso a terminal na rede da empresa: cole o prompt abaixo e troque sp_COLE_AQUI_O_TOKEN pelo seu token. No chat da web o Claude roda fora da rede e não alcança o Pages. O token vale como a sua conta: use um token só para isso, com validade curta, e revogue depois. Se puder, guarde-o na variável PAGES_TOKEN em vez de colar no chat.

      

      

      
Para atualizar uma página sem perder a versão anterior, apague o arquivo (vai para a lixeira por 30 dias) e publique de novo; override=true sobrescreve sem lixeira.
